## Fatto — stile di marca (il frontend deve rispecchiare marchio e app Android)
- [x] **Palette** identica (`Theme/Palette.swift`): verde `#3C9650`, giallo `#F0C607`, rosso `#B7332D` fissi; rampe, neutri sabbia/inchiostro, tutti i livelli
      di superficie, **chiaro e scuro** (colori dinamici). Stati: verde = confermato, giallo = da rivedere, rosso = in uscita (si leggono da `Theme.primary/secondary/error`).

      Font di sistema (SF) al posto di Roboto: è l'equivalente nativo.

- [x] **Sfondo ambiente** (`AmbientBackground`): colore del tema + tre macchie verde/giallo/rosso, fermo di default (animato solo se richiesto e se non è attiva la riduzione del movimento).
- [x] **Vetro** (`Glass.swift`): materiale sfocato + tinta + filo di luce sul bordo + ombra morbida; `GlassPanel`.
- [x] **Pulsanti** (`Buttons.swift`): pieno (gradiente + ombra colorata), vetro con bordo, testo, icona; molla alla pressione e vibrazione leggera.
- [x] **Card con profondità**, **occhiello di sezione** (maiuscolo spaziato), **SelectField** (menù con spunta), **logo** (`Surfaces.swift`).
- [x] **Barra di navigazione a pillola** di vetro (`SiciliaNavBar`): solo icone, la voce attiva si allarga con l'etichetta, l'indicatore scivola con una molla,
      rimbalzo dell'icona; sezioni sfogliabili con un gesto (come il pager Android); nessuna intestazione nelle sezioni di primo livello.
- [x] **Login** nello stile Android: gradiente verde fisso, logo, "RENTAL HOMES" giallo, pulsante bianco, campi traslucidi (solo email/password per ora).

## Differenze volute rispetto all'Android
- Solo iPhone: nessun layout per Fold/cerniera/tablet (`ui/adaptive/*` segnato `n/a`).
- I dialog e i menù usano gli alert/sheet/menù di sistema, che su iOS sono già in vetro; il blur dietro al dialog non va riscritto.
- Sfocatura con il materiale di sistema invece di una libreria (Haze).
