# SiciliaHost iOS

App iOS nativa (SwiftUI) per la gestione delle case vacanza SiciliaHost: riscrittura dell'app Android
`CaseVacanzeApp`. Stesso backend Firebase (`siciliahostmanager`) dell'app Android e del sito.
